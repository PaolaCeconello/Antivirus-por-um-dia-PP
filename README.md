# Antivirus por um dia - Jogo em Java

Implementação em Java de um jogo de tabuleiro colaborativo para dois jogadores com interface no terminal. Trabalho em grupo desenvolvido para a disciplina Paradigmas da Programação, cursada em 2026/2.

## Funcionalidades
- O objetivo do jogo é encontrar a fonte de infecção do vírus em até 25 turnos.
- O jogo é organizado por turnos, na ordem jogador 1, jogador 2 e inimigos.
- Dois tipo de jogadores diferentes: simples e de suporte; Ambos tem um valor de ataque e defesa.
- O jogador simples tem 3 ações possíveis: movimentar, atacar e procurar.
- o jogadorsuporte tem 4 ações possíveis: movimentar, atacar, procurar e recuperar defesa.
- Os jogadores se movimentam pelos setores.
- Há 3 tipos de setores: setores normal, setor oculto e setor privado.
- No setores normais não há restrições, no setor oculto o ataque ao inimigo pode ou não levar dano e no setor privado não é possível executar a ação "procurar".
- Inimigos gerados aleatoriamente entre os setores.
- Inimigos tem valor de ataque e defesa.
